# Filter Tracker

Track home and automotive filter replacement schedules by time or mileage.

## Features
- Time-based tracking (furnace, water filters, air purifiers, etc.)
- Mileage-based tracking (engine air, cabin air, oil filter, etc.)
- Alerts for filters due within 7 days or 500 miles
- Persistent storage via localStorage

## Getting Started

```bash
npm install
npm run dev
```

Then open http://localhost:5173 in your browser.

## Build for Production

```bash
npm run build
```
